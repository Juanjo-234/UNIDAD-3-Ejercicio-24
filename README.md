Resolución del ejercicio N°24 de la unidad 3 de programación 2.
Este programa modela un sistema de gestión de dispositivos tecnológicos que administra diferentes equipos mediante el uso de herencia, atributos protegidos, polimorfismo y sobrescritura de métodos en Java.

Clases utilizadas
Dispositivo: Clase base que almacena los datos comunes (marca, modelo, precioBase) y define el método general para mostrar la información.
Smartphone: Clase hija que extiende de Dispositivo e incorpora atributos específicos como los megapíxeles de la cámara y la capacidad de almacenamiento, sobrescribiendo el método de visualización.
Laptop: Clase hija que extiende de Dispositivo e incorpora atributos como el procesador y la memoria RAM, sobrescribiendo también el método de visualización.
